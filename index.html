¿Cómo funciona?

FocusFlow es una aplicación de demostración hecha solo con HTML, JavaScript y una imagen. Funciona en GitHub Pages sin servidor ni cuenta de usuario.

La técnica Pomodoro

  • Trabaja 25 minutos en una sola cosa.
  • Haz una pausa corta de 5 minutos.
  • Después de cuatro sesiones de trabajo completadas, descansa 15 minutos.

Puedes cambiar de modo cuando quieras. Las sesiones completadas se contabilizan en este navegador. Para que el temporizador suene, mantén abierta la pestaña y el sonido del dispositivo activado.

Privacidad: no se envían datos a ningún servidor. Los registros se almacenan en localStorage y pueden desaparecer al borrar los datos del navegador.
